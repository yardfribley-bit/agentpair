这项发现怎么处理

  1. 删掉记忆和背景里的密码

    进入 WorkBuddy 的头像 → 设置 → 记忆，删除对应的登录资料和 Token。保留环境用途即可，不保存实际密码。

    若仍出现，继续检查自定义指令、本地记忆和项目规则。

  2. 关闭记忆，再开新会话

    在设置 → 记忆中关闭功能。重启 WorkBuddy，新建会话，避免旧对话继续带上原来的资料。

    查看官方设置说明 ↗

  3. 更换仍有效的密码或 Token

    删除记忆不能让已经出现过的凭据失效。请在对应服务中更换密码或撤销令牌。
