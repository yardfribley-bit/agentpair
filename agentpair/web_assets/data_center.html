条件语法与示例

支持字段 = 或 !=、单引号或双引号，使用 && 表示同时满足、|| 表示任一满足。&& 优先于 ||；当前不支持括号或通配符。字段按完整值匹配；command 也支持已识别的程序名。!= 会包含未记录该值的记录。

app="workbuddy" && tool="Bash"skill="agent-browser"mcp="doc-mcp" && mcp_method="create_with_markdown"

tool 搜索原始工具名；skill 搜索已识别的 Skill 加载或说明读取；mcp 搜索 MCP 服务，mcp_method 搜索其方法。命令包装调用的原始工具可能仍是 Bash 或 js。target_domain 搜索请求目标域名，domain 搜索任何位置出现的域名。也支持 function、command、app、collector、ip 等字段。
