# Backplanes 临时报告导出扩展

1. 在 Chrome 打开 chrome://extensions，开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择此目录。
3. 在 Chrome 登录 Backplanes，打开目标报告，展开需要的证据。
4. 点击扩展按钮，再点击“导出当前页正文”。
5. 将生成的 backplanes-report-*.txt 发给 Codex 分析。

仅在用户点击时读取当前页可见正文、标题和 URL。没有后台脚本、网络请求、Cookie/存储读取或自动上传。未展开、未加载的内容不在导出范围内；图表图像和布局不保留。当前扩展适用于 Chrome，不能直接安装到 Codex 内置浏览器。

完成后可在扩展管理页移除本扩展。
