# AgentPair

**一个可发布任务、持续对话、看见协作过程的双 Agent 结队编程框架。**

你提出需求，Navigator 规划与复核，Driver 实现与返回结果。你可以继续追问、补充约束或要求修改，两个 Agent 在同一任务的上下文中推进下一轮。

AgentPair 的核心是协作机制，不是某一个网站、模型或云厂商。网站分析只是验证框架的示例适配器；本轮不接入 AgentReins 审计。

## 两个 Agent 如何结队

| 角色 | 职责 | 交给对方的内容 |
| --- | --- | --- |
| Navigator | 理解需求、拆解步骤、检查结果、调整方向 | 计划、约束、已有上下文 |
| Driver | 按计划实现代码建议或执行已注册工具 | 实现 / 分析、证据、未解决的问题 |

一次对话轮次：**用户要求 → Navigator 规划 → Driver 实施 → Navigator 复核 → 用户反馈**。下一轮承接已有对话，不是重新启动无历史的两个问答。

框架负责消息交接、任务状态、历史、停止条件和过程展示；适配器负责这类任务能调用什么工具、怎样验证结果。模型不能靠一句“测试通过”替代真实执行器。

## Web 工作台

- 发布新任务，选择任务类型并说明目标与验收标准。
- 在同一任务里追加消息，继续下一轮；不同任务的上下文隔离。
- 双角色面板、带方向的动态交接、当前阶段与消息内容；点击角色查看结构化记录。
- 查看每轮结果、证据和用量，取消后阻止后续调用，导出完整记录。
- 显式回放已经完成的交接。回放不调用模型，动画不冒充网络抓包或实时逐 token 输出。

## 当前能力与边界

已实现任务队列、SQLite 持久化、多轮历史、真实角色模型接口、Navigator 本地角色 + SSH Driver 节点、登录 / Origin / CSRF 校验、取消与估算预算预留。实验每任务最多 **3轮**，每轮 **3次角色调用**。重启将未完成任务标为中断，不自动重放付费请求。

**尚未实现：生成代码的隔离执行、自动测试、根据真实测试失败自主修复、提交 Git。** 编程任务可以产出与复核代码建议，但还不是完整的自主软件开发系统。离线 coordinator 验证了修复 / 换方案状态机，脚本化反馈不代表真实测试执行成功。

## 快速验证

无需第三方 Python 包：

```sh
python3 -m unittest -v
python3 -m agentpair.demo
```

第二条是离线模拟，不调用模型、不执行生成代码；成功状态为 simulated_pass。真实双节点工作台见 [运行说明](PLATFORM.md)。部署脚本含本次节点和临时密钥路径，尚非通用云部署器。

## 框架与示例分开

```text
Web 任务发布 / 对话 / 协作画布
                ↓
TaskEngine：队列、历史、轮次、预算、取消、事件
                ↓
Navigator  ←  计划 / 结果交接  →  Driver
                ↓
任务适配器：结队编程讨论 / 网站取证 / 后续扩展
```

- discussion：结队编程与方案讨论，输出代码建议或文字结果，不执行代码。
- public_site：示例适配器，读取公网 IPv4 网站、有限静态资源、官方注册与 ASN 路由信息。无扫描、登录或漏洞利用。未配置商业威胁情报、历史恶意记录或被动 DNS，不能据此宣布目标安全。

协议见 [设计文档](DESIGN.md)。交互结构参考 [AutoGen Studio](https://microsoft.github.io/autogen/dev/user-guide/autogenstudio-user-guide/usage.html) 和 [Langflow 节点连线](https://docs.langflow.org/concepts-overview)，不宣称使用其引擎。

## 费用与安全

- 发布任务不会创建云主机、扩容或延长租期。
- 模型额度按历史价格估算并预留，**不是供应商人民币硬限额**。失败请求也占预留，重启不重置。
- 可写工作台仅监听 Navigator loopback，经 SSH 通道访问；公网 HTTP 页面仅展示公开快照。
- 任务会发送到已配置的模型中转服务，不要输入密钥或敏感数据。凭据不进入 Web 响应和对话记录。
- 密钥、runtime/、数据库、密码与 runs/ 不进入 Git。生产仍需正规 HTTPS、用户隔离、凭据管理及可靠的云端租期回收。
