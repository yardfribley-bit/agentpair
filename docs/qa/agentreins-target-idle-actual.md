# 目标范围与空闲更新优化

日期：2026-10-12。代码、Release 构建和实际换包完成；活跃场景负载下降，但完全空闲 CPU 仍待实测。

## 行为修改

ProcessGuard 根目标从多个 Agent 收窄到 WorkBuddy、Codex，保留 macOS ChatGPT 宿主归属以维持当前 Codex 进程树。父子关系继续关联实际执行子进程。未知所有者仅允许可执行文件名称匹配目标，命令参数/项目路径里出现目标名称不构成归属证据。目标范围外的 Agent 不再触发资源、网络和命令规则链路。系统 PID 元信息仍仅作瞬时发现索引。

正常没有目标的空快照不再触发全机 ps 回退或被报告为采集失败；真正扫描失败仍回退。无目标发现间隔为 2 秒，有目标时保留原来的高频子树观察。最后目标退出时清理观察臂、发布退出一次。没有目标时跳过网络与代理查询。

资源未变化时去掉每 30 秒强制生成观察证据；首次可见性、实际资源变化、Hook 请求和退出证据保留。界面发布前比较任务/证据版本及显示元信息，发布时间/健康心跳不触发无变化 JSON 编码；只有成功交付才推进比较基线，补全请求/重载使用交付代数强制恢复。

源数据与既有数据库未删除，采集正文、真实子进程和新增网络证据仍保留。

## 实际 CPU

旧包与新包约 40 秒独立窗口，新包预热约两分钟，测量无编译/采样分析干扰。Codex 本次任务正在执行，两次均属于活跃状态，负载不是固定实验。

| 进程 | 旧 CPU 时间折算 | 新 CPU 时间折算 | 新 ps 均值 |
| --- | ---: | ---: | ---: |
| 主进程 | 72.4% | 46.1% | 19.1% |
| WebKit 内容 | 20.6% | 10.5% | 4.3% |
| WebKit GPU | 3.2% | 1.6% | 1.0% |
| 合计 | 96.2% | 58.2% | 24.4% |

100% 约一个逻辑核心。采用 CPU 时间增量作为窗口负载；ps 平滑口径不同，不能混用。可观察到本轮窗口下降，不能声称固定因果降幅，也不能认定空闲性能验收完成。未退出用户当前 Codex/WorkBuddy 来制造空闲场景。

测量后的 3 秒执行栈仍有 live-presentation、live-encoding、采集与 checkpoint 工作；样本数量不是 CPU 百分比。活跃任务的投影和变化交付仍有进一步优化空间。
