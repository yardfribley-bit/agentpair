# 普通 exec 可读展示验收

日期：2026-10-08，北京时间。用户要求补齐执行器包装的可读性，默认先解释动作、对象和实际结果，原始命令及返回可展开。

## 功能范围

- 普通 exec 从原始请求代码静态识别内部函数、字面量参数、命令及对象。不运行采集的代码，也不分析返回中的代码来虚构执行动作。
- 支持 Codex `Script completed`、`Wall time`、`Output` 包装，以及 `text` / `input_text` / `output_text` 文本块、命令退出码与仍运行的返回。
- 读取代码、变更文件、运行测试、语法检查、读取运行输出等明确调用使用可读动作标签。文件、行段、请求 URL 等来自参数证据。
- 多项内部请求和外层返回分开；顺序、`i`、`chunk_id` 不用来伪造调用配对。仅完整、全字面量且唯一的简单单调用模板可以显示明确标注的外层单操作对应。
- 测试数量、错误信息、文件内容及 JSON 实际字段作为摘要。命令成功退出不代表业务任务完成；Skill 说明读取不代表最终产物。
- 列表保留用户输入、Agent、上报机器，最多默认显示三项操作、两份返回，其余折叠；参数、代码与运行辅助字段默认收起。原始记录、按需求展开、记录详情及关联步骤使用同一可读结构。

## 数据和资源边界

历史记录按当前页读取并投影，无需重建索引，`DataCenter.VERSION` 保持 5。按页预算为最多四十份来源记录、二百万字符、累计约 0.25 秒来源读取与投影耗时。列表其他匹配/关联查询的等待时间不扣此预算。预算为软限制，进行中的单次读取可能越限，后续非缓存读取立即停止。预算不足显示尚未解析；已取得调用但未展开已有返回时，明确提示“已有外层返回，本页未展开；记录详情可查看”，不误报未采集。记录详情与完整原文仍可访问。

单份源代码解析最多 64,000 字符、十六项操作、十二份返回；详情内容仍有明确展示上限，源数据不被改写。调用与返回查找保持账号、设备、Agent、来源会话和快照边界。

## 真实样本核对

使用本机权限为 600 的三份不同真实 exec 调用及配对返回，没有将原始样本发送到大模型。

- 一个外层脚本已完成，但实际返回同时含命令退出码 1 与另一个仍运行的会话：状态分别保留，没有统一标成功。
- 一份并行脚本的三个命令返回退出码 0：没有按输出顺序或 `i` 自动配给三个内部请求。
- 一份测试请求只返回脚本仍运行：没有宣称测试已经通过。

样本分类名称仅用于候选筛选，不作为调用事实；文件读取性质必须从实际调用参数确认。新独立验收包含读取 Python 源码后正文出现 `db.execute(...)` 的案例，仍标为读出的代码而不是执行数据库操作。
