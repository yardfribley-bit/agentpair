## 关联冲突追加修复

独立合成验收发现父消息指向需求 A、轮次编号指向输入 B 时，详情会展示 A 的输入并扩展 B 的动作。修复统一核对父消息、原生轮次、唯一调用返回配对；明确锚点不一致时保持未确认并列出冲突 ID。详情停止冲突链扩展，后续成员自身有冲突或明确属于另一输入时也被排除。合法一致关系、原始调用返回配对和标明为邻近的事实记录仍可查看。
