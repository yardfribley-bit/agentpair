# 可装配 Driver 运行时

当前实现 `tool_registry.py` 与 `driver_runtime.py`：

- 工具注册包含说明、输入格式、健康检查和调用实现；重复注册、未知工具、非法参数拒绝执行。
- 文件读写在独立任务工作区；原生 Bash 具有网络，Git、构建与测试可由终端组合执行。
- 终端不继承服务进程环境中的 API 密钥；执行 90 秒超时，有界输出并清理进程组。
- Driver 循环根据上一步真实结果继续行动，记录工具证据和累计 token；每轮保存检查点。
- 入口要求独立 Driver 标志及用户明确选择云端结对；浏览器执行器缺失或无明确目标 URL 时在付费开机前拒绝。
- 浏览器底层提取 WebLens 的 Lightpanda 客户端及测试，对外注册 AgentPair browser.* 工具；不部署 WebLens 产品。
- 工具事件逐步回传到任务时间线；限额内文本产物持久化到 Navigator 并可下载。

隔离边界是独立 VM，不是 Docker。工作目录校验不是系统沙箱，原生终端能够访问该 VM
用户可访问的文件；不要在 Driver 存放云管理密钥、其他租户任务或长期凭据。
