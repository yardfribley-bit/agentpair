# 凭据安全发现第一版

仅处理密码、私钥、密钥、令牌进入模型输入。页面不再展示其他威胁、泛化调查方法或 ZCode 案例。原始交互审计和 AgentPair 复核接口保留兼容，主页面以此单一威胁为中心。

## 数据链路

采集入库 → 同事务扫描 → 发现/出现记录持久化 → 页面读取结果 → 所属账号记录处理 → 后续新会话增量检查。

启动时回填现有历史记录。扫描版本或正文哈希变化后重算；相同内容重传跳过。独立 finding_id 按设备和同一凭据聚合，内部使用服务器随机密钥的 HMAC，不对外返回凭据值或其指纹。密码候选邻近片段遮蔽凭据，保留原文偏移、角色及完整正文哈希。私钥按整段内容聚合。

检测补充自然背景里的 root/密码、Lab Token，排除目录、明确占位符、Bearer 代码字面量。自动步骤为本地检测与明确背景线索判断。设备所属账号可发起单项 AgentPair 复核，确认向 aigc.gether.net 的 deepseek-v3.2 发送本页任务与遮蔽片段后才创建任务。专项证据包只复核本项凭据，保留来源和有效性未知，结果绑定发现及正文哈希；不会自动外发真实片段。

## 页面

发现与危害、实际片段、任务提取依据、来源未知项、WorkBuddy官方设置说明、处理项与观察状态。仅捕获请求显示请求正文证据；应用记录明确发送未证实。任务不能可靠分离时不补造。仍有效凭据的更换与记忆清理分别说明。

所有访客可读，只有设备所属账号可 POST /api/devices/credential-remediation，保留CSRF校验。记录清理背景/关闭记忆/更换凭据，不自动执行这些动作；用户报告不等同于独立确认。

## 验证

检查处理记录后收到、采集时间也晚于处理时间的新会话；基线会话、缺少会话ID、截断/无法解析的记录、过度超前的设备时间不作为阴性验证。收到新会话后自动判定：等待新会话 / 这批新会话未再出现 / 新会话仍携带。

每次新的处理报告创建新的观察边界。零样本不通过；再出现可重开；没有“已彻底解决”的自动结论。无命中只说明已检查新会话中的文字，不能证明旧凭据失效、完整采集、没有图片/编码内容或没有其他上传通道。

## 当前边界

- 不测试登录、不撤销凭据、不改WorkBuddy。
- 不向外部模型自动发送真实采集片段。
- 所属设备合并后需重建该设备的凭据索引；当前启动回填可为迁移后的规范设备生成索引，旧别名不展示。
- 后续扩展其他威胁需独立检测器与证据标准，复用发现→出现→处置→验证结构；本版不宣称多威胁覆盖。
