采集范围与实现状态

macOS 与 Windows 采用一致界面和事件格式，各自发现日志、维护读取位置与上传确认。Codex 归档目录纳入计划；现有代码尚未默认同时扫描它。

WorkBuddy 的实际日志路径、reasoning 和工具字段需要分别验证。日志未提供的内容显示“来源未提供”，不能表示“已采全”。

超大记录场景展示现有 16 MiB 阻塞边界；分片处理与 Windows 适配尚待实现。当前示例不代表已支持 Windows 实时采集。
