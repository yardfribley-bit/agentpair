# 工作记忆助手：任务归属修复

问题不是任务卡片写死，而是查询绑定到了错误的真实任务。旧链路把词项重叠当成主题相关，选第一项后就让模型解释它；模型回答得完整也不能纠正错误的任务归属。

## 修复范围

1. 用户提问边界：历史压缩摘要、Markdown 包装摘要和后台工具完成通知不作为新任务；已有派生索引在查询与任务列表中同样排除这些记录。原始日志保持原样，没有进行全量索引重建。
2. 意图理解：模型区分原任务主体、原任务动作和本次关注的问题。来源名称不参与主题匹配。
3. 本机召回：完整文件名保留，不将相似文件名混用；提问中的明确实体必须匹配。按词项辨识度、任务正文、操作意图排序，减少长引用的词数优势。先读取任务标题，仅对主题词或实体做正文检索。
4. 归属与追问：指代当前任务的追问先绑定当前任务；新命名的任务可以切换。未明确指定其他 Agent 时，优先检索正在讨论的 Agent，找不到相关项再扩大范围。用户指定的 Agent 和日期范围保持有效。
5. 无匹配与歧义：相近任务展示来源、日期和原提问供确认；没有任务或没有上下文时提示补充信息。未解决的提问中断追问上下文，避免复用更早的答案。
6. 证据回答：模型引用范围校验后再复核概述与证据的支持关系，防止将未记录、Agent 声明、超时搜索写成已核验结论。格式错误只做有限重试，不接受无效引用。新缓存版本不复用旧的未经复核回答。

## 验证

使用预先冻结的 12 个问题，覆盖文件创建、文件读取、文档分析、公众号脚本、记忆操作、视频校验、开机启动项、TLS 动画、Intel 安装及不存在／不明确的任务。

- 修复前：5 个对应正确任务，7 个选错。
- 修复后：9 个直接回答，1 个相近任务需确认，2 个未匹配／缺少上下文停止回答；本批没有选错。
- 目标 ID 仅用于测试对照及拦截错误证据发送，不传给检索；仅在界面已经提出候选后测试用户选择。
- 另有 5 项原有 SSH／天气切换回归；新对话来源有歧义时增加确认，保留问题与预期任务不变。
- 部分回答复用了修复后的模型缓存，不能以此宣称模型请求性能提升。
- 本机单元及 Qt 回归共 54 项。完整真实任务评估数据保留在本机，不进入 Git。

## 限制

当前仍是模型语义改写加本机词项／实体检索，未实现向量召回。排名差距不是校准过的置信概率。模型复核仍可能出错；上述样本通过不代表任意提问都能命中。背景通知的旧派生记录仅被排除，尚未将每条旧通知重新关联到具体后台工具任务。没有修改、删除或补造原始证据。
